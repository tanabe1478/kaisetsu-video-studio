# 解説台本の表記と読み

## 字幕と読み上げを分離する

`narration[].text` は人が読む台本・字幕。`speech` は音声合成向けの読み上げ表記。読み方の都合で字幕を漢数字やカタカナに置き換えない。

- コード中の値、計算結果、小数、倍率、バージョンは字幕に半角数字で記す。例：`27`、`2倍`、`0.5`、`8.5`、`0.10.11`。
- バージョンのドットは小数点ではなく区切り。`0.10.11` を「ゼロ点十点十一」と台本へ書かない。読み上げは各区切りを識別できるようにする（例：文中で「バージョン、ゼロ、じゅう、じゅういち」）。数字の桁や区切りを変えない。
- 小数の字幕は `0.5`。音声合成で補正が必要ならspeech側に「れいてんご」などを指定する。小数点以下は桁ごとに読み、バージョンの読みと区別する。
- コード上の識別子・型名は字幕で綴りを保持し、必要な読み仮名はspeechだけに置く。
- 「一緒に」「一部」「一時停止」「一つの結果」など通常の日本語は機械的に数字へ変換しない。コード上の具体的な値と一般的な言い回しを区別する。

例：

```json
{
  "text": "整数の8を小数へ変換してから、0.5を足すので、8.5になるのだ。",
  "speech": "整数のはちを小数へ変換してから、れいてんごを足すので、はちてんごになるのだ。"
}
```

## 改訂と確認

ユーザーが渡した編集済み台本を起点にし、元の生成スクリプトから作り直さない。指摘の同種の問題を全編で確認するが、章立てや無関係な文言・コード・演出を勝手に変更しない。元ファイルを残して改訂版と変更箇所を保存する。

字幕と読み上げで、数値・符号・単位・バージョンの各要素・文の意味が一致することを確認する。コードと説明の値を照合する。漢数字の検索は候補抽出にとどめ、文脈を見て判断する。

エディターで字幕を書き換えるとspeechも同じ文に更新されるので、読み仮名を補正するのは文言確定後に行う。音声を試聴していない場合は、表記確認と実際の発音確認を区別して報告する。
