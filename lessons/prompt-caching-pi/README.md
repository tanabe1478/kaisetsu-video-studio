# プロンプトキャッシュとPiの設計

目標20分、2人の掛け合い。10章・30場面・180セリフ。音声付き本編は20分2.75秒で生成済み。[本編の保存先・検証記録](FULL_VIDEO.md)。

## 成果物

- `lesson.json`：台本ノートに読み込める台本。`targetMinutes`と`productionBrief`はトップレベル。
- `SCRIPT.md`：読みやすい会話の全文。字幕表記が正本。読み補正はJSONの`speech`に保持。
- `SOURCES.md`：公式資料・固定コミット・教材独自の例の区別と場面別リンク。
- `VALIDATION.md`：検証範囲、推定尺と未確認事項。
- `preview_motion.py`：保存済み台本から無音の黒板プレビュー2本を生成。

導入・まとめ・場面の間・問いかけの待ち時間を含む。話速は全編1.0。推定は約6189文字、5.5文字/秒と間のモデルによる。音声の実測ではない。エディターの±25%の目安では15:38〜25:24になる。追加依頼後の合成実測は20分2.75秒。話速・説明量・間を変更せず本編を生成できた。

## プレビュー

`output/prompt-caching-pi-20260908/prefix-change.mp4`と`compaction.mp4`。各30秒、1280×720、12fps、無音。6セリフを各5秒に割り当てた動きの確認用で、音声合成後のタイミングではない。図はすべて模式図。料金例も架空単位の算術であり、実測値や見積もりではない。

再生成はリポジトリルートから `.venv/bin/python lessons/prompt-caching-pi/preview_motion.py`。既存ファイルは上書きしない。編集した台本からの改訂では、その編集用コピーを新しい起点にする。

## 前提と範囲

視聴者・口調が未指定のため、LLM利用経験のある開発者向けの平易な会話を採用。参考記事の逐語訳ではなく、仕組みを独自の例で説明し、Piの該当コードを確認する教材。最低トークン数・料金・モデル一覧の網羅的比較は行わない。ソースは静的解析のみ。API呼び出しやPi本体の実行・ベンチマークはしていない。
