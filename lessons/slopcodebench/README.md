## 再生成

既存編集の起点はlesson.json。古い生成スクリプトで上書きしない。新しい出力先を使う。

```sh
.venv/bin/python motion/prepare_lesson.py lessons/slopcodebench/lesson.json output/slopcodebench-new
node motion/render_lesson.mjs output/slopcodebench-new --preview-scene=17
# 画像・代表動画を確認後
node motion/render_lesson.mjs output/slopcodebench-new
```

ローカルVOICEVOXは127.0.0.1:50021。Remotion 4.0.522、1280×720、24fps。固定6セリフの場面構成に対応するSlopCodeBench専用の描画であり、任意の台本を自動で図解設計するものではない。

静的boardはエディターの予備表示。motionはRemotion用の演出情報であり、旧Python方式のboardAnimation v1を実装したという意味ではない。エディター内のプレビューボタンから同じRemotion動画が出る統合は未実装。音声付きpreview.mp4を確認用に同梱した。

音声合成用のspeechだけを修正し、行数、値、同じ表、割るの読みを補正。確認した3セリフはexpectedKanaによる再生成時の照合を保存した。聴感の全編レビューとは区別する。

最終成果物はoutput/slopcodebench-full-20260912-v3。Gitには動画・音声・個人用エディターコピーを含めない。
