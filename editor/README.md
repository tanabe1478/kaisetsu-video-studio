# 台本ノート

AIが作った台本の章・場面・セリフを編集して、対象ごとに改訂メモを残すローカルエディターです。

## 起動

リポジトリのルートで `./start-editor.ps1` を実行し、表示される `http://127.0.0.1:8765/` を開きます。ChatGPTに「台本エディターを開いて」と依頼しても構いません。

エディターの実行にはPython 3.10以降の標準ライブラリだけを使います。VOICEVOXやNode.jsの起動・インストールは不要です。
手動でサーバーを起動する場合は `python editor/server.py`。終了はCtrl+Cです。別ポートでは `python editor/server.py --port 8766`。

## 編集の流れ

1. 初回はMoonBit台本の編集用コピーが開きます。「台本を開く」で別の台本JSON・バックアップを読み込むか、白紙から作れます。
2. 左の章や場面を選び、中央で見出しやセリフを修正します。章・場面をドラッグで移動でき、矢印ボタンでも並べ替えられます。場面の所属章はプルダウンでも変更できます。
3. セリフの「メモ＋」や右の対象選択から、AIへの具体的な指摘を追加します。メモは項目の移動後も紐付きます。削除した項目へのメモも残ります。
4. 「AIに渡す」で編集済み台本・メモを一緒に保存し、表示された依頼文をChatGPTに貼り付けます。
5. AIが作った改訂版のJSONは「台本を開く」で新しい編集用コピーとして読み込み、確認します。

セリフの字幕を変えると、読み上げ文も同じ内容に更新します。「読み上げの表記を調整」で固有名詞の読みを補正できます。
メモは「対応済み」に切り替えられます。JSONから改訂版を読み込む場合、以前のメモは元の編集用コピーに残ります。メモも引き継ぐにはoutline形式のバックアップを利用します。

## 保存と復元

- 変更から約0.65秒後に自動保存。Ctrl+Sで即時保存、Ctrl+Zで元に戻す、Ctrl+Shift+Zでやり直します。履歴は画面を開いている間の直近80回分です。
- 「バックアップ」は未保存の変更も含むJSONをダウンロードします。保存失敗・競合時にも使えます。「台本を開く」から復元できます。
- 複数画面で同じ台本を編集した場合は古い内容での上書きを止めます。バックアップして再読み込みしてください。自動マージはしません。
- 編集用コピー：`editor/workspace/<ID>.json`。
- AI向け書き出し：`editor/workspace/exports/<時刻-ID>/` 内の `script.json`、`feedback.md`、`outline.json`。
- 元の `lesson.json` や `demo.json` は上書きしません。作業データはGit管理対象外です。OneDrive配下に置いた場合はOneDriveの同期設定が適用されます。

AIが改訂するときは、編集済み `script.json` を起点にしてください。教材の生成スクリプトを実行すると、ユーザーの編集が入っていない元の台本が再生成されます。
動画にする場合は、ルートで `python studio.py editor/workspace/exports/<時刻-ID>/script.json --output output/revised` を実行します。動画生成には従来の依存関係とVOICEVOXが必要です。

## 現在の範囲

### テンポ・立ち絵の自動提案と場面プレビュー

場面上部の「演出を自動提案」で、各セリフに話速・追加の間・表情・ポーズを設定します。台本全体の設定にある「全編の演出を自動提案」でもまとめて適用できます。
現在はローカルのキーワード・コード有無に基づくルール方式です。AIモデルへの自動問い合わせはしません。問いかけ・挨拶・答え・注意点を手掛かりにし、原則2セリフは同じ差分を保持します。台本の意味を完全に理解するものではないため、プレビューで確認してください。

各セリフの「テンポ・立ち絵」を開くと、話速（0.5〜2）、追加の間（0〜10秒）、表情・ポーズを手動調整できます。手動変更したセリフは、その後の自動提案で上書きしません。「戻す」で提案全体を取り消せます。
追加の間はVOICEVOXが生成した音声の後に入ります。最後のセリフの後には場面末尾の間も加わります。自動提案は既存の小問の待ち時間を考慮し、重複する追加の間を避けます。

「▶ 場面プレビュー」でその場面だけを生成し、動画プレーヤーで再生します。VOICEVOXの起動と従来の動画生成依存関係・素材が必要です。生成は同時に1件、場面は1500文字まで、最大10分で打ち切ります。生成中も台本を編集できますが、動画はボタンを押した時点の内容です。編集後は再生成してください。
出力先は `editor/workspace/previews/<ID>/`。音声・字幕・タイムライン・MP4を保存します。過去に削除した教材動画を再生成する操作ではありません。

JSONの各 `narration[]` に任意の `direction` を保存します。`speed`、`pause`、`expression`、`pose` を指定でき、`source: "auto"` は自動提案、`source: "manual"` またはsource省略は手動指定として扱います。directionがない従来台本は従来の話速・場面差分・間で生成されます。AIが演出を付ける場合も同じ形式を使えます。

章・場面・セリフの編集、並べ替え、複製、検索、演出設定、対象付きメモ、バックアップ、AIへのファイル受け渡しに対応しています。
画面内からのAI呼び出し、改訂差分の採否、共同編集、動画タイムラインは未実装です。動画生成はプレビューボタンで明示的に実行します。

ブラウザーに `document.modelContext.registerTool` が存在する場合のみ、台本の読み取りとメモ追加ツールを登録します。これは任意の拡張で、通常操作には不要です。実ブラウザーのWebMCP接続は未検証です。

## 開発・検証

```powershell
python -m unittest discover -s editor -p 'test_*.py' -v
npm ci --prefix editor
npm test --prefix editor
npm run check --prefix editor
```

Node.jsとjsdomはテスト専用です。HTTP API・一時ディレクトリへの保存、競合拒否、台本情報の保持、およびjsdom上の編集操作を自動検証します。実ブラウザーでの描画・ドラッグ操作の目視確認とは区別しています。

### 表情・ポーズの画像プレビュー

「テンポ・立ち絵」と「画面に表示する内容・演出」を開くと、選択中の組み合わせの画像が表示されます。表情・ポーズを変えると画像も切り替わります。目・口は静止状態です。
このPCでは16通りを準備済みです。別環境や素材変更後は `python build_sprite_previews.py` で準備します。素材変更時はassets/previews内の古い画像を退避してから再実行してください。画像はGitに含めません。
