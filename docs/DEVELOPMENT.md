# 開発方針と制作ノウハウ

## 目的

ChatGPTと共同で台本と演出を編集し、パターン化された解説動画をローカルで再生成する。
当面は個人利用を前提とし、配布用GUIよりも再現可能な制作工程を優先する。
ずんだもんから始め、将来は他の解説キャラクターにも拡張する。

## 現在の構成

1. demo.jsonでセリフ、見出し、箇条書き、表情、ポーズを指定。
2. VOICEVOXの話者一覧から名前とスタイルを解決して音声合成。
3. セリフ・話者ID・話速・エンジンバージョンをキーにWAVをキャッシュ。
4. 坂本アヒル無印2.3のPSDをpsd-toolsで合成。目・眉・口・腕を切り替える。
5. Pillowで日本語字幕と背景を描画し、FFmpegへRGBフレームを送る。
6. MP4、WAV、SRT、場面時刻JSONと確認用PNGを保存。

音声を24fpsのフレーム境界まで無音で埋め、後続場面の同期ずれを防ぐ。
口パクは音量閾値による開閉。字幕区間ごとに合成したWAVの実長から表示時刻を計算する。
字幕表示と音声用表記を分けて、英語の技術用語の読みを指定できる。
字幕の区間同期と、厳密な音素・逐語同期とは区別する。
長文は字幕を均等な2行へ分ける。長尺動画ではコード枠、章一覧、小問の間を使う。
立ち絵の上下の微動は、ユーザーからぶれて見えるとの指摘を受け削除した。定位置で表情・口・目を切り替える。
BGMはaudio_mix.pyでローカル音源を読み、発話中のRMSより既定22dB小さく設定して合成する。
口パク判定にはBGM混合前のナレーションを使い、音楽で口が動かないようにする。
ナレーションWAVを保持しているので、BGMだけの調整は映像を再描画せずに最終化処理で反映できる。

## 素材の扱い

指定の「無印」は作者配布ページの素材2.3。V3.2や「改」と混同しない。
入手元・チェックサム・利用条件はREADMEに記録し、原本のreadmeもローカルに保持する。
PSDのレイヤー名に依存するため、別バージョンへ差し替える場合はマッピングを確認する。
立ち絵・生成PNG・音声・動画はGitへ登録しない。取得元から各環境に配置する。
作者のクレジットとVOICEVOXの音源クレジットを動画に残す。

## 検証方法

- 短い台本で実際に合成・書き出しする。
- 確認用PNGで字幕のはみ出し、表情、ポーズ、クレジットを確認する。
- FFmpegで出力動画の映像・音声を全編デコードし、エラーがないことを確認する。
- 同期方式を変更した場合は、場面境界と字幕・口パクを再生して確認する。
- デコード成功は、聴感や厳密な同期の確認を意味しない。

## 更新の残し方

コードと対応する仕様・使い方を同じコミットで更新する。
ユーザーから見た変更と検証内容はCHANGELOG.mdに記録する。
未実装の案は実装済みの機能と区別し、大きな機能はブランチで開発する。

## 台本アウトライン編集（2026-09-06追加）

Python標準ライブラリのローカルHTTPサーバーとHTML/CSS/JavaScriptを使用。通常利用にnpmやクラウド接続は不要。
台本を章・場面・セリフの構造に分け、項目ごとの安定したIDへメモを紐付ける。元の台本の追加フィールドも保持する。
編集用コピーはeditor/workspaceに保存し、Gitから除外する。保存は一時ファイルからの置換とrevision照合で行う。
AIへは編集済み台本・未対応/対応済みメモ・バックアップのスナップショットを渡す。改訂時は生成用スクリプトではなく編集済み台本を起点にする。
次の候補はセリフの音声プレビュー、AI改訂案との比較・採否、場面単位の動画プレビュー。
検証手順と操作説明はeditor/README.mdを参照。
